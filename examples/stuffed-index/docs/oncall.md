# On-call rotation

Rotations run Wednesday to Wednesday so that handover never lands on a Monday.
Primary carries the pager. Secondary is a thirty minute backstop and is not
expected to be at a keyboard.

Swapping a shift needs no approval. Update the roster and tell the channel.

Nobody is on call for more than one week in four. If the roster would break
that, the rotation is short and the team lead covers the gap.
