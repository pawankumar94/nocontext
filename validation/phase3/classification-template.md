# Phase 3 post-review classification template

Use this only after a completed blind-review record identifies the accepted
questions. The person doing this step may inspect the navigation surface.

For every accepted probe, classify the route before editing the surface:

- **coverage**: the surface should point to the expected document but has no
  pointer to it.
- **vocabulary**: the surface points to the expected document, but its pointer
  does not route the question.

Do not call a coverage failure a vocabulary failure. Do not use held-out
questions to choose edits.

Copy this file to `classification-YYYY-MM-DD-<reviewer>.md` and record one row
for every accepted probe.
